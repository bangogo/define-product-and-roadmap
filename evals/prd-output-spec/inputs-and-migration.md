# 回归输入、落位与继承（合成用例）

本目录 HTML 均为合成回归样本，不声称有真实用户、工单系统或宿主调用。模板本身承担新产品 HTML 样本；`requested-markdown.md` 承担用户明确指定非 HTML 的输出样本。

## 存量产品输入

- 用户陈述：团队一直用人工登记表管理工单，处理人员登记结果、负责人确认结案；没有提交真实系统日志。因此“有限真实使用”仅代表用例中的用户陈述，具体状态尚未独立验证。
- 当前审阅入口：`existing-prd-draft.1.html`。只请求 PRD，不创建 Roadmap。
- 第一轮反馈：关闭前需附处理证据。落位：需求 P0-01 原规则、验收、工单处理状态表新增“处理证据”列。
- 第二轮反馈：改由当班负责人确认。落位：需求 P0-01 原规则、验收、表格新增“确认责任”列、SVG 第三节点与文字路径。最终入口：`existing-prd-draft.3.html`。

修订样本在 HTML 内使用 4.1.0 `data-migration-table="v1"` 表。该表覆盖当前需求 ID，并按字段说明语义变化与信息损失；本文件保留输入叙述和人工核对，不替代 HTML 内迁移表。

| 输入轮次 | 反馈 | 落位 | 核对 |
|---|---|---|---|
| 第一轮 | 关闭前需附处理证据 | P0-01 原规则、验收、工单处理状态表“处理证据”列 | 语义变化写入 HTML 迁移表 |
| 第二轮 | 改由当班负责人确认 | P0-01 原规则、验收、“确认责任”列、SVG 第三节点与文字路径 | 语义变化写入 HTML 迁移表 |

D-01 的可选方向为 `manual-close`（保持负责人确认）和 `auto-close`（自动结案）；两步确认先选方向，再选确认／修改／暂缓。方向 ID 只来自 HTML 卡片声明。
