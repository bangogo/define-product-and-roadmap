# 证据包：AI 直接生成先行（故意做坏的负例）

某公众号写作助手项目。作者已确认要用 AI 辅助创作，PRD 与 Roadmap 结构大体合规、风险修饰项声明了 AI，但 AI 能力直接上「生成 + 自动发布执行」，没有任何评价层。该 fixture 用于评估技能能否按「先评价 → 再生成 → 后执行」的默认优先序审计出以下问题：

- AI 生成能力缺少先评价层（评估维度、评估载体、基线采集动作、裁决机制、解锁条件）。
- 成功信号整表 `待验证` 且无最小基线采集动作。
- R1 已 `In Progress`（AI 生成）却无评估载体与裁决机制；R2 直接解锁自动发布执行。
- 附加呈现问题：正文有 `（0.6.0 起）` 考古括号与逐字重复的推进公式。
